# UI text and localisation (ADR-0009)

- **Locales.** English is the source; the shipped locales and their style guides are listed
  in `docs/i18n/README.md`. Don't assume Hungarian is the only other language: discover the
  locales (`ls crates/i18n/locales`, `values-*` folders, xcstrings `localizations`).
- **Where text lives.**
  - Studio and CLI: Fluent files in `crates/i18n/locales/<code>/*.ftl`.
  - Android: `mobile/android/app/src/main/res/values/` and `values-<code>/`.
  - iOS: `mobile/ios/Labely/Labely/*.xcstrings` (one localisation per locale per key).
- **Every locale has the same keys as English.** Add, rename or delete a key in all locales in
  the same change. `cargo xtask i18n-check` fails CI otherwise, and also checks that every iOS
  `L("key")` literal exists in `Localizable.xcstrings`.
- **Placeholders and plurals.** Keep placeholders intact; give each language the CLDR plural
  categories it needs (Fluent selectors, Android `<plurals>`, xcstrings plural variations).
- **Terms and register** come from `docs/i18n/<code>.md`. A new term goes into that glossary
  in the same change.
- **Command errors.** A command error's `message` stays stable English for agents (ADR-0009);
  frontends localise for display (e.g. the `error-*` keys in `common.ftl`), never `message`.

Use the `i18n-key` skill to add a key everywhere at once, and the `translation-reviewer` agent
to review translated text. Adding a whole locale: the checklist in `docs/i18n/README.md`.
